# 사이트 설계도(PRD) — (미정)

작성일: 2026-10-13 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
넘어졌다가 다시 시작하려는 사람에게, 지금 마음에 맞는 위로와 용기의 글을 밝은 카드로 건네는 사이트.

## 2. 손님
- 누가: 다시 시작하는 사람 (실패하거나 넘어진 뒤 다시 일어날 용기가 필요한 사람)
- 어디서 알고 오나: 인스타그램

## 3. 손님이 바라는 것 (카드를 보며)
1. 지금 내 마음에 맞는 글을 고르고 싶다
2. 마음에 드는 카드를 폰에 저장하고 싶다
3. 소중한 사람에게 카드를 보내고 싶다

## 4. 믿게 할 증거 (실제로 있는 것만)
- 아직 없음 — 카드 글과 그림은 이번에 새로 만든다
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 내 마음에 맞는 카드 받기
- 누르면: 지금 기분을 고르는 화면 → 그 기분에 맞는 카드 한 장

## 6. 페이지 구성 (위에서 아래로, 한 페이지)
1. 첫 화면 — 한 문장 + "내 마음에 맞는 카드 받기" 버튼
2. 기분 고르기 — 지금 마음을 고르는 버튼들 (예: 넘어졌을 때 · 지쳐서 버티기 힘들 때 · 조급하고 흔들릴 때 등, 정확한 목록은 만들 때 정함)
3. 카드 한 장 — 글 + 색·도형 그림, 아래에 [다른 카드] [저장하기] [보내기]
4. 기분별 카드 모아 보기
5. 후기 자리 (비워 둠)

## 7. 문의 폼에서 받을 것
- 없음 — 이번 사이트에는 문의 폼과 연락 창구를 두지 않는다

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: 없음 (무료)
- 시간: (미정)
- 위치: (미정)
- 연락 방법: 없음
- 카드 글: 사용자가 준 예시 세 문장은 사용자가 쓴 글이 아니다. 분위기와 말투를 분석하는 참고로만 쓰고, 카드에 그대로 옮기지 않는다. 카드 글은 클로드가 새로 쓴다.

## 9. 이번에 넣지 않을 것
- 회원가입·로그인
- 방문자가 직접 카드 만들기
- 결제·후원
- 사연 남기기
- 문의 폼·관리자 페이지

## 10. 첫 화면 한 문장 후보
1. 넘어진 자리에서도, 우리는 무언가를 줍고 일어나요.
2. 오늘 당신 마음에 필요한 한 장을 골라 드릴게요.
3. 다시 시작하는 당신에게, 작은 응원 한 장.

## 11. 다음에 할 것
- 9번 항목들 (회원가입, 직접 카드 만들기, 결제·후원, 사연 남기기)
- 사용자가 직접 만든 AI 이미지로 카드 그림 바꾸기
- 사이트 이름 정하기

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 발랄한 · 참고 디자인: 없음 — 클로드가 정함
- 카드 글: 예시 문장의 결(넘어짐에서 배우기, 초라한 시간을 버티기, 소중한 것에 집중하기)을 분석해 클로드가 새로 쓴다. 숫자·출처·명언을 지어내지 않는다
- 카드 그림: 이미지 파일 없이 밝은 색과 도형으로 그린다
- 저장하기: 카드를 이미지로 내려받기 · 보내기: 폰의 공유 기능(안 되면 링크 복사)
- 문의 저장: 아니오
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. 기분 고르기 → 카드 → 저장·보내기까지 만든다
3. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제
