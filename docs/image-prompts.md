# 카드 그림 프롬프트 (마음마다 한 장, 4장)

## 쓰는 법

1. GPT(나노바나나)나 미드저니에 **참고 이미지(창가에서 책 읽는 여자 그림)를 같이 첨부**하고 아래 프롬프트를 붙여 넣어요.
2. 비율은 **4:3 가로**로 뽑아요. 카드 위쪽 그림 칸이 4:3이에요.
3. 다 뽑으면 `my_site/images/` 폴더에 아래 이름으로 저장해요. png·jpg·webp 다 돼요.

| 마음 | 파일 이름 |
|---|---|
| 넘어졌을 때 | `images/fall.png` |
| 버티기 힘들 때 | `images/endure.png` |
| 조급하고 흔들릴 때 | `images/rush.png` |
| 나를 잃어버린 것 같을 때 | `images/lost.png` |

4. 사이트를 새로 고치면 그림이 바로 들어가요. 저장하기로 받는 이미지에도 같이 들어가요.

**네 장 모두 같은 사람이 나오게** 하려고 인물 설명을 똑같이 넣었어요. 첫 장이 마음에 들면, 다음 장을 뽑을 때 그 첫 장도 같이 첨부하면 얼굴이 더 잘 맞아요.
그림 안에 **글자는 넣지 않아요**. 카드 글은 사이트가 그림 아래에 따로 얹어요.
